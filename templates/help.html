Guide

How StartPage keeps your daily launchpad tidy.

The homepage lists links ordered by a dynamic rank: every redirect bumps the rank up, and inactivity slowly nudges it down. Anything that drifts below 1.0 is eligible for cleanup, so your most-used links stay at the top.

Everyday workflow

  • Browse & search. Use the global search box in the navbar—results stream in without reloading thanks to HTMX.
  • Dashboard maintenance. The Dashboard groups cards by health so you can edit or delete low-rank items before they disappear.
  • Add links quickly. Drop a URL on the Add page and we seed it with the average rank so it naturally finds its place.
  • Automatic pruning. Each redirect updates the accessed timestamp and rank. Stale links (rank < 1) are the first candidates for deletion.

Modify the database

The application stores everything in a local SQLite file at:

{{ db_path }}

  1. In-app editing. Use the Add/Edit forms for day-to-day work—each save runs through services/db_utils.py to validate data and keep ranks balanced.
  2. Direct SQL tweaks. When you need to bulk-edit, open the database with sqlite3 {{ db_path }} and manipulate the links table. The core columns are id, name, url, rank, and accessed (Unix timestamp). 
    sqlite3 {{ db_path }}
UPDATE links SET rank = 1.0 WHERE name = 'Docs';
.quit
  3. Automated scripts. Feel free to import services.db_utils into your own automation to reuse helpers such as save_link, get_links, or delete_link.

Tip: the database is disposable state—commit schema changes, not the file itself.

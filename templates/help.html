Guide

Everything you need to use StartPage every day.

Links are ranked by how often (and how recently) you open them. Each click gently bumps the rank up, idle links drift down, and anything below 1.0 becomes a pruning candidate so the list stays lean.

Navigate & search

Pinned links

The home page shows the highest-ranked items first. Use the “Pinned Links” filter pills to narrow the view to a single tag.

Global search

Use the search bar in the navbar. Results stream in without a reload and you can keep scrolling to fetch additional batches.

Add & edit links

  • Smart tag suggestions. When you type in the tag field, suggestions pop up automatically and filter as you go. Click a pill to insert the tag without worrying about typos.
  • Balanced rank. Newly added links start with the average rank so they appear near the top but settle naturally over time.
  • Bulk actions. The dashboard lets you select several links at once to delete or append tags in batches.

Stay organized with tags

Tag directory. Visit /tags to see every tag, how many links it touches, and quick delete controls.

Renaming & merging. Use the new inline Rename button to fix spelling mistakes or consolidate duplicates. If you pick an existing name, StartPage automatically merges the links so you only keep one tag.

Filtering. Click any badge to jump into a tag-scoped view. Infinite scroll and search continue to work inside that filtered list.

Automatic cleanup. Tags disappear when they no longer belong to any links, so you never have to manually tidy empty labels.

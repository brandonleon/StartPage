Guide

Everything you need to use StartPage every day.

Links are ranked by how often (and how recently) you open them. Each click gently bumps the rank up, idle links drift down, and anything below 1.0 becomes a pruning candidate so the list stays lean.

Navigate & search

Pinned links

The home page shows the highest-ranked items first. Use the “Pinned Links” filter pills to narrow the view to a single tag.

Global search

Use the search bar in the navbar. Results stream in without a reload and you can keep scrolling to fetch additional batches.

Embed mode & themes

StartPage can be embedded as a minimal widget or integrated into other pages using URL parameters.

Embed mode

Add ?embed=true to any URL to hide the navigation bar and footer, creating a clean widget view perfect for browser extensions or iframe embeds.

Example: http://localhost:8080/?embed=true

Theme parameter

Force a specific theme with ?theme=dark or ?theme=light. Without this parameter, StartPage uses your system preference.

Example: http://localhost:8080/?theme=dark

Combine parameters: Use both together for a themed embed.

Example: http://localhost:8080/?embed=true&theme=dark

All navigation within embed mode (tag filters, search, pagination) automatically preserves these parameters so your configuration stays consistent.

Add & edit links

  • Auto-fill link names. When adding a new link, just paste the URL and leave the name field blank. StartPage automatically fetches the page title and fills it in for you. A spinner appears while fetching, and you can always override it with your own custom name.
  • Duplicate detection. As you type a URL or name, StartPage checks in real-time if it already exists in your collection. You'll see a warning if you're about to create a duplicate, helping you avoid clutter.
  • Smart tag suggestions. When you type in the tag field, suggestions pop up automatically and filter as you go. Click a pill to insert the tag without worrying about typos. Tags keep only letters, numbers, and hyphens—spaces become hyphens automatically and everything else is discarded.
  • Balanced rank. Newly added links start with the average rank so they appear near the top but settle naturally over time.

Temporary links

Flag short-lived bookmarks that expire automatically—perfect for project-specific resources, event pages, or anything you only need for a limited time.

  • How to create. When adding or editing a link, toggle the "Make this a temporary link" switch. Choose a duration preset (default is 24 hours) or set a custom expiration time.
  • Automatic cleanup. Temporary links are automatically deleted when their timer expires. The cleanup runs in the background every 10 minutes and also happens whenever you load the homepage.
  • Visual indicators. Temporary links appear with a special badge showing their expiration time, so you always know when they'll disappear.
  • Configurable defaults. Visit /settings to adjust the default duration, enable/disable the feature, or change the maximum custom hours allowed.

Dashboard & bulk operations

The dashboard at /dashboard gives you a complete view of all your links with powerful batch editing capabilities.

  • Bulk delete. Select multiple links using the checkboxes, then click "Delete selected" to remove them all at once. Perfect for cleaning up old or irrelevant bookmarks.
  • Bulk tag. Select multiple links and use the bulk tag field to append tags to all of them simultaneously. Great for organizing imported links or categorizing groups of bookmarks.
  • Export your data. The dashboard banner links to /exports/csv and /exports/json for creating backups or migrating to another instance.
  • Import links. Use the import form to bulk-upload links from CSV or JSON files. Existing links (matched by ID) are updated, new ones are created.

Frecency in plain English

Every link gets a score that blends frequency (rank) and recency (how long since you last opened it). The exact formula is:

score = 10000 * rank * (3.75 / ((0.0001 * (now - accessed) + 1) + 0.25))
  • rank increases by 1 each time you click the link from StartPage.
  • now - accessed grows as a link sits idle, reducing its score so stale entries drift down.
  • Links with a score below rank 1.0 become pruning candidates and are eventually removed.

Statistics & insights

Visit /stats to see comprehensive analytics about your link collection and usage patterns.

Rank overview

View total links, sum/average/max rank, and see what percentage of your rank capacity is currently in use. This helps you understand when automatic pruning might kick in.

Top & recent links

See your top 10 most accessed links by rank, recently accessed links, and the 10 least accessed links that are at risk of being pruned.

Access patterns

Track when you last accessed any link and identify stale bookmarks that haven't been used in a while.

Pruning warnings

Links are color-coded by health status: red for "prune soon" (rank < 1.1), yellow for "watchlist" (rank < 2.5), and green for "healthy".

Settings & configuration

Customize how StartPage works by visiting /settings. All changes take effect immediately and are saved to your configuration file.

Frecency settings

Batch size: Control how many links appear per page (default: 20). Increase for fewer page loads, decrease for faster loading.

Max rank threshold: Set the total rank pool allowed before automatic cleanup kicks in (default: 1000).

Temporary link controls

Enable/disable: Toggle the temporary links feature on or off.

Default duration: Set how long temporary links last by default (default: 24 hours).

Max custom hours: Limit how long users can set custom expiration times (default: 720 hours / 30 days).

Navigation behavior

Reset filter on click: Choose whether clicking a link from a tag-filtered view returns you to the full list or keeps the filter active.

Theme preference

Use the theme toggle button in the navbar (sun/moon icon) to switch between light and dark modes. Your preference is saved in your browser.

Import & export

  • Export anytime: The dashboard banner links to /exports/csv and /exports/json. CSV files include id,name,url,rank,accessed,tags (semicolon-separated tags) and JSON returns an array with the same fields.
  • Import in bulk: Use the "Import links" form on /dashboard (or POST to /imports) with a matching CSV or JSON payload. Import uses strict ID-based merging: if a row's id matches an existing link, that link is updated with new values (name, url, rank, accessed, tags). If the id doesn't match or is blank, a new link is created. This means you can export, modify tags or other fields, and re-import to update your links while preserving their frecency scores.
  • CLI workflows: Headless installs can run uv run python -m services.io_utils csv -o backups/startpage-links.csv to export, then curl -F format=json -F upload=@links.json http://your-host/imports (or csv) to re-import without touching the UI.
  • Important notes: Link names and URLs must be unique. Leading/trailing whitespace is automatically trimmed during import. If a row would violate uniqueness constraints (duplicate name or URL with different ID), that row is skipped and the import continues with remaining rows. The summary will show how many links were created, updated, or skipped.

Stay organized with tags

Tag directory. Visit /tags to see every tag, how many links it touches, and quick delete controls.

Renaming & merging. Use the new inline Rename button to fix spelling mistakes or consolidate duplicates. If you pick an existing name, StartPage automatically merges the links so you only keep one tag.

Filtering. Click any badge to jump into a tag-scoped view. Infinite scroll and search continue to work inside that filtered list.

Automatic cleanup. Tags disappear when they no longer belong to any links, so you never have to manually tidy empty labels.

Guide

Everything you need to use StartPage every day.

Links are ranked by how often (and how recently) you open them. Each click gently bumps the rank up, idle links drift down, and anything below 1.0 becomes a pruning candidate so the list stays lean.

Navigate & search

Pinned links

The home page shows the highest-ranked items first. Use the “Pinned Links” filter pills to narrow the view to a single tag.

Global search

Use the search bar in the navbar. Results stream in without a reload and you can keep scrolling to fetch additional batches.

Add & edit links

  • Smart tag suggestions. When you type in the tag field, suggestions pop up automatically and filter as you go. Click a pill to insert the tag without worrying about typos. Tags keep only letters, numbers, and hyphens—spaces become hyphens automatically and everything else is discarded.
  • Balanced rank. Newly added links start with the average rank so they appear near the top but settle naturally over time.
  • Bulk actions. The dashboard lets you select several links at once to delete or append tags in batches.

Frecency in plain English

Every link gets a score that blends frequency (rank) and recency (how long since you last opened it). The exact formula is:

score = 10000 * rank * (3.75 / ((0.0001 * (now - accessed) + 1) + 0.25))
  • rank increases by 1 each time you click the link from StartPage.
  • now - accessed grows as a link sits idle, reducing its score so stale entries drift down.
  • Links with a score below rank 1.0 become pruning candidates and are eventually removed.

Import & export

  • Export anytime: The dashboard banner links to /exports/csv and /exports/json. CSV files include id,name,url,rank,accessed,tags (semicolon-separated tags) and JSON returns an array with the same fields.
  • Import in bulk: Use the "Import links" form on /dashboard (or POST to /imports) with a matching CSV or JSON payload. Import uses strict ID-based merging: if a row's id matches an existing link, that link is updated with new values (name, url, rank, accessed, tags). If the id doesn't match or is blank, a new link is created. This means you can export, modify tags or other fields, and re-import to update your links while preserving their frecency scores.
  • CLI workflows: Headless installs can run uv run python -m services.io_utils csv -o backups/startpage-links.csv to export, then curl -F format=json -F upload=@links.json http://your-host/imports (or csv) to re-import without touching the UI.
  • Important notes: Link names and URLs must be unique. Leading/trailing whitespace is automatically trimmed during import. If a row would violate uniqueness constraints (duplicate name or URL with different ID), that row is skipped and the import continues with remaining rows. The summary will show how many links were created, updated, or skipped.

Stay organized with tags

Tag directory. Visit /tags to see every tag, how many links it touches, and quick delete controls.

Renaming & merging. Use the new inline Rename button to fix spelling mistakes or consolidate duplicates. If you pick an existing name, StartPage automatically merges the links so you only keep one tag.

Filtering. Click any badge to jump into a tag-scoped view. Infinite scroll and search continue to work inside that filtered list.

Automatic cleanup. Tags disappear when they no longer belong to any links, so you never have to manually tidy empty labels.
